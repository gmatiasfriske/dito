DICTADO - COMO INSTALAR
=======================

Requisitos:
- Windows 10 ou 11, 64 bits.
- Python 3.11 ou 3.12 (marque "Add python.exe to PATH" na instalacao).
- GPU NVIDIA recomendada. Sem ela, o app funciona em CPU, bem mais lento.
- Cerca de 5 GB livres para o ambiente e 3 GB para o modelo na primeira execucao.

Passo a passo (Prompt de Comando na pasta do Dictado):

1. Crie o ambiente:
   py -3.11 -m venv .venv
   .venv\Scripts\activate
   python -m pip install --upgrade pip

2. Instale o PyTorch com CUDA (NVIDIA):
   python -m pip install torch==2.9.1 torchaudio==2.9.1 --index-url https://download.pytorch.org/whl/cu128

   Sem NVIDIA, use CPU:
   python -m pip install torch==2.9.1 torchaudio==2.9.1 --index-url https://download.pytorch.org/whl/cpu

3. Instale o restante:
   python -m pip install -r requirements.txt

4. Abra o Dictado:
   python main.py

Na primeira abertura, o modelo (~2,9 GB) sera baixado do HuggingFace.
A pilula fica cinza/girando ate ficar verde. Isso pode demorar alguns minutos.

Como usar:
- Ctrl+Y comeca a gravar; Ctrl+Y de novo para e transcreve.
- O texto e colado no programa que estiver em foco.
- Em repouso, os 7 pontinhos no circulo mostram a sensibilidade. Passe o mouse
  sobre a pilula e use a rodinha para ajustar antes ou durante a gravacao.

Se algo der errado:
- Veja as ultimas linhas de dictado.log.
- Se a instalacao falhar, apague a pasta .venv e repita os passos acima.
- Nao coloque o projeto dentro de "Arquivos de Programas"; use Downloads,
  Documentos ou Desktop.
